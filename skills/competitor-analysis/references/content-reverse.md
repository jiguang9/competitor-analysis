# 内容逆向工程

用系统性方法分析竞品的高互动内容，提炼背后的结构规律，然后用差异化的角度切入同类话题。

## 核心原则：借结构，不抄表达

逆向工程不是复制竞品的选题和文案，而是提炼结构规律（开头方式、段落逻辑、互动设计），再用自己的差异化观点、第一手证据和用户语言重写。模仿选题会让品牌跟着竞品走；学习结构能让品牌在同类话题上建立更强的竞争优势。

**不建议模仿的内容模式**需要在输出中单独指出：例如依赖夸大宣传、误导性数据、抄袭他人原创案例、或利用平台漏洞（如标题党到脱离内容本身）获取的互动——这些结构不值得借鉴，即使它们的互动数据好看。

## 分析流程

1. 收集用户粘贴/上传的竞品内容，或公开可访问的博客、官网文章、视频文字稿。
2. 区分**内容事实**（标题、发布时间、结构、包含哪些论据）、**表达方式**（语气、修辞、视觉风格）和**效果推断**（互动量、评论情绪——仅在有实际数据时才做判断，不能凭感觉推测"这篇一定很火"）。
3. 提取标题、开头、结构、论证方式、案例使用、CTA（行动号召）和评论区反馈规律。
4. 归纳重复出现的内容模式（例如：痛点开头、反常识钩子、数字列举式标题、结尾互动设计）。
5. 结合数据源（评论中的高频问题、用户痛点）区分：
   - **饱和话题**：竞品反复覆盖，内容供给已经很多。
   - **蓝海话题**：竞品覆盖少但用户关注度高。
   - **可超越话题**：竞品有覆盖但内容质量明显不足。
   - **评论区未回答问题**：用户在评论中反复问，但没有任何一方专门写过内容回答。
6. 判断机会时结合用户痛点，不能只寻找"竞品没写过"的关键词——没写过可能是因为需求本就不存在，需要有用户痛点或搜索需求的佐证。

## 话题空白的证据强度

每个话题空白建议标注证据强度：

- 强：既有评论区高频提问佐证，又确认竞品内容库中没有对应内容。
- 中：只有其中一项佐证（例如有高频提问但未系统核实竞品内容库，或反过来）。
- 弱：仅凭直觉判断"竞品好像没写过"，未做系统核实。

## 输出结构

- 爆款结构规律（标题模式、开头方式、内容结构、语气风格、结尾互动设计）
- 主题和内容类型分布
- 用户痛点与内容承接关系（哪些痛点已经被内容覆盖，哪些还没有）
- 话题空白清单，每项标注证据强度
- 3 个"相同结构、不同观点"的内容框架（给出可直接使用的框架，而非成品文案）
- 不建议模仿的内容模式及原因

## 边界提醒

不编造具体的互动数据或流量数字。如果用户没有提供实际的点赞/评论/转发数据，只能描述"结构上通常更容易引发互动"这类基于内容结构的合理判断，并标注为 inference，不能给出具体数字。
