# 数据来源与采集流程

竞品情报的原材料分散在不同平台，系统化收集优于随机刷屏。

## 数据来源清单（按类型）

| 类型 | 来源示例 |
|---|---|
| 内容渠道 | 官网博客、公众号、小红书/抖音/LinkedIn/X 等账号 |
| 用户声音 | 电商评论、App Store / Google Play 评论、社群/论坛截图（用户提供） |
| 广告素材 | 广告透明度库（如平台公开的广告库）、搜索结果中的广告位 |
| KOL 合作 | 达人笔记、直播切片、标注为合作的内容 |
| 公开信息 | 媒体报道、融资新闻、招聘信息（用于判断战略方向） |
| SEO/SEM | 搜索引擎排名、关键词布局、落地页 |

不同市场权重不同：

- 面向中国市场的品牌：电商评论（京东/天猫等）、小红书、抖音、公众号权重更高；小红书和抖音等平台的站内私域数据（如私信、粉丝群内容）不可抓取，只能由用户主动粘贴或上传。
- 面向海外市场的品牌：官网、G2/Capterra 等评论平台、Product Hunt、Reddit、YouTube 评论权重更高。
- To B / SaaS：官网定价页、案例研究页、招聘信息（判断团队扩张方向）、公开融资信息权重更高。
- To C / 消费品：电商评论、社媒爆款内容、KOL 合作权重更高。

## 公开网页收集流程

1. 从竞品官网开始：首页、产品页、价格页、关于我们/团队页、博客最新几篇。
2. 用公开搜索补充：竞品名 + "评价" "怎么样" "缺点" "vs" "对比" 等关键词。
3. 对每一条重要信息，尽量打开原始页面核实，而不是只依赖搜索结果摘要。搜索结果摘要只能作为线索，用来决定是否值得深入。
4. 记录访问失败或无法访问的页面（付费墙、需要登录、404 等），不要跳过不提。

## 搜索预算

- Quick 模式：每个竞品建议 3–8 次搜索/页面访问，聚焦官网核心页面 + 1–2 次关键词搜索。
- Deep 模式：每个竞品建议 10–20 次搜索/页面访问，覆盖官网、评论、内容、新闻、更新记录。
- 竞品数量越多，单个竞品的搜索预算应相应下调，避免总时间线性膨胀导致响应过慢；如果用户给出的竞品超过 3 个且要求 Deep，建议用户先收窄或分批处理。

## 来源失败处理

无法访问的来源必须在报告的"数据覆盖范围与缺失证据"部分明确列出，使用统一措辞：

- "获取失败"：页面存在但无法访问（网络错误、超时、结构无法解析）。
- "需要登录/付费墙"：内容存在但被访问限制阻挡。
- "未查到"：公开搜索没有返回相关结果。

这三种状态都不能被写成"没有变化""没有相关信息"或直接省略——它们和"竞品确实没有该功能/该内容"是完全不同的结论，混淆会导致比较表出现错误的"否"。

## 数据来源的信任分级

- 一手来源（官网、竞品官方账号发布的内容、平台公开的定价页）：可直接引用为事实。
- 二手来源（媒体报道、行业分析文章）：引用时注明来源方，视为"有一定可信度的说法"，重大结论仍建议交叉验证。
- 用户生成内容（评论、社媒讨论）：代表个体声音，不能单条当作事实结论，需要按 `sentiment.md` 的方法处理频次和分布。
- 搜索引擎摘要/AI 生成摘要：仅作为线索，重要事实必须回到原始页面核实后才能写入报告。
