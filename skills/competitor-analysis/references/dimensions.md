# 五维度分析框架

竞品情报不是"跟踪竞品在做什么"，而是"理解竞品为什么这样做，以及这对我方意味着什么"。五个维度覆盖了竞品分析中最有战略价值的信息类型。同一份报告中的所有竞品必须回答相同的问题、使用相同的比较维度——不能给竞品 A 做五维度分析，给竞品 B 只做两维度。

## D1 · 用户定位与差异化

竞品在服务谁、怎么定位自己。如果竞品和我方其实服务的是不同用户，很多看似竞争的情况其实是不同市场。

关键问题：
- 竞品的目标用户和我方有何核心差异（年龄/职业/消费动机/公司规模等，视行业而定）？
- 竞品的核心价值主张（官网标语、定位表述）是什么？
- 市场上还有哪个用户群没有被充分服务？
- 竞品定位是否存在明显空白或弱点？

## D2 · 内容营销策略

竞品在创作什么内容、投入什么渠道、什么内容获得了最高互动。这直接告诉你哪些话题有流量机会。

关键问题：
- 竞品的主要内容渠道和发布频率是什么？
- 竞品爆款内容的共同结构特征是什么（详见 `content-reverse.md`）？
- 竞品内容覆盖了哪些话题，忽视了哪些？
- 竞品的 KOL/KOC 合作策略是什么？

## D3 · 定价与促销策略

竞品的定价逻辑和促销习惯。价格背后是竞品对自身价值的定义。

关键问题：
- 竞品核心 SKU 的定价区间是多少？近期是否调整过定价或 SKU 结构？
- 竞品的促销习惯（频率、力度、形式）是什么？
- 用户对竞品定价的感受是"贵"还是"值"（需要有证据支撑，不能只靠猜测）？

## D4 · 渠道与增长策略

竞品在哪里获客、如何留住用户。渠道策略的变化往往是竞品战略调整的早期信号。

关键问题：
- 竞品的主要付费渠道和免费流量来源是什么？
- 竞品近期渠道投入有何明显变化？
- 竞品的私域/复购策略是什么？
- 竞品在哪个渠道明显弱于市场平均水平？

## D5 · 用户口碑与产品反馈

竞品的真实用户评价，包括好评和差评。差评是金矿：用户抱怨竞品的每一点，都是解决后可以赢得这批用户的机会。

关键问题：
- 竞品差评的高频主题是什么（这些是差异化机会）？
- 竞品好评中被反复提及的核心优势是什么（这才是需要真正超越的部分）？
- 竞品用户描述需求时的原话有哪些可以用于理解真实语言习惯？
- 竞品用户流失/转品的核心原因是什么？

详细的采集和分析方法见 `sentiment.md`。

## 默认经验规则：D5 与 D2 优先级最高

如果时间有限，经验上 D5（用户口碑）和 D2（内容策略）通常是投入产出比最高的两个维度：D5 的竞品差评直接提示可以解决的问题，D2 的爆款分析直接提示可以创作的内容方向。

**这是一条默认的经验规则，不是普遍事实。** 在以下情况应该调整优先级：
- 分析目的明确是"制定定价策略"时，D3 应优先。
- 分析目的明确是"评估渠道扩张"时，D4 应优先。
- 竞品口碑数据（评论）完全无法获取时，不要为了凑够 D5 而编造或过度推断，应如实标注"D5 证据不足"，把精力转向其他维度。

## 统一比较维度与状态标注

在同一份报告的比较表中，所有竞品必须使用相同的行（同一组问题）。每个单元格的状态只使用三种值：

| 状态 | 含义 |
|---|---|
| 是 | 有明确证据支持该竞品具备/存在该项 |
| 否 | 有明确证据证明该竞品不存在/不支持该项 |
| 未知 | 没有查到可靠证据，不能判断 |

**禁止把"没有查到"写成"没有"。** 搜索不到某竞品的定价页面，状态应标"未知"，而不是"否"或留空。

## Quick / Deep 覆盖范围

| 维度 | Quick 默认覆盖 | Deep 额外覆盖 |
|---|---|---|
| D1 定位 | 官网首页、产品页表述 | 结合搜索结果和第三方描述交叉验证 |
| D2 内容 | 官网博客/最新几篇文章标题和结构 | 近 3 个月高互动内容、KOL合作抽样 |
| D3 定价 | 官网价格页 | 促销历史、用户对价格的评价 |
| D4 渠道 | 官网可见的渠道入口（社媒图标、下载链接等） | 结合公开搜索判断渠道投入变化 |
| D5 口碑 | 有限公开搜索中的口碑片段（如有） | 系统化评论采集与情感分析，见 `sentiment.md` |

Quick 模式下没有覆盖到的维度，报告中直接标注"未在本次 Quick 分析范围内，标记为未知"，不要略过不提。
