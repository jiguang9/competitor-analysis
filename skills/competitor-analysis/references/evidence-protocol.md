# 证据协议

每一条重要结论都必须能够回答："这是事实、推断，还是未知？依据是什么？"

## 三种类型

| Type | 含义 | 使用场景 |
|---|---|---|
| verified fact | 已经通过原始来源核实的事实 | 产品功能、价格、公开客户案例等可以直接在原始页面确认的信息 |
| inference | 基于证据做出的战略判断或推测 | "竞品可能在测试新渠道""此举可能意在..." 这类判断 |
| unknown | 没有查到可靠证据 | 搜索或访问后仍无法确认 |

## 证据字段

记录重要结论时（尤其是将进入报告"证据账本"的条目），使用以下字段：

| 字段 | 说明 |
|---|---|
| Claim | 事实或判断的具体表述 |
| Subject | 所属品牌或竞品 |
| Dimension | 所属分析维度（D1–D5 或"综合"） |
| Type | verified fact / inference / unknown |
| Source | 原始 URL，或注明"用户提供数据" |
| Quote | 支撑结论的短原文（不超过必要长度，避免整段复制） |
| Published at | 内容发布日期；无法确认则填"未知" |
| Accessed at | 本次采集/核实的日期 |
| Confidence | high / medium / low |

## 规则

1. **产品、价格、客户、融资、市场份额、销量等事实性内容必须引用来源。** 没有来源的这类陈述不能出现在报告正文，只能出现在"待核实"清单中。
2. **战略判断标记为 inference，并说明依据来自哪些观察。** 例如"竞品可能在筹备海外市场（inference，依据：近 2 个月招聘信息中出现 3 个海外岗位，Source: [URL]）"。
3. **无法核实的信息标记为 unknown，写入"待核实"清单**，不要为了让报告看起来完整而省略或含糊带过。
4. **搜索结果摘要只能作为线索**，重要事实应尽量打开原始页面确认后再写入报告；如果时间/权限不允许打开原始页面，在 Confidence 中标注 low，并说明仅依据搜索摘要。
5. **高风险结论重点复核**：价格、销量、市场份额、融资金额、客户数量、合规资质、独家能力等对决策影响大且容易被营销話术夸大的信息，尽量交叉验证至少两个来源；不要求为每一句战略建议都寻找外部引用。
6. **Confidence 判断参考：**
   - high：一手来源直接确认，或多个独立来源一致。
   - medium：单一来源，或来源为二手报道但可信度较高。
   - low：仅有间接线索、过时信息，或依赖搜索摘要未核实原文。

## 证据强弱标准（用于舆情和内容分析）

- 单条证据（只有 1 条评论/1 篇内容提及）：标记"个案"或"弱证据"，不能作为主题结论单独呈现，除非明确注明样本量。
- 2–4 条独立证据：可以作为一个"值得关注"的主题，但仍建议注明证据数量。
- 5 条及以上独立证据：可以作为报告中的主要主题呈现。

## 来源日期的处理

- Published at 无法确认时，不要臆测日期，直接标注"未知"。
- Accessed at 始终填写本次实际采集/核实的日期，用于后续报告对比时判断信息是否已经过时。
- 涉及"近期""最近"等相对表述时，在报告中转换为具体的采集日期区间，避免几周后回看报告产生歧义。
